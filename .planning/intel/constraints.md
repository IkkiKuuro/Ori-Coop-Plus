# Constraints (ingest synthesis)

## Protocolo e sincronizacao — envelope UDP versionado e IDs de pacote
- source: docs/protocol.md
- type: protocol
- content: Envelope UDP obrigatorio de 24 bytes little-endian (magic 0x4F43 + versao 2 + flags Reliable/AckPresent + seq uint32 wrap-safe + clientId + token + packetId + ackSeq); divergencia recusada com Reject 106 sem criar sessao. Handshake em 3 vias Hello 100 / Welcome 101 / Confirm 102; IDs incrementais nunca reutilizados; 0 = servidor, 999 = dummy. Pacotes criticos (chat -5, CONFIG_SYNC 16, TELEPORT_REQUEST 15, SYNC_ABILITY 10, SYNC_LEVER 11, SYNC_DOOR 12, SYNC_WORLDEVENT 14, SKILL 7, COLOR 6, DISCONNECT 4) = confiaveis com SysAck 103 + retry 250 ms x3; PLAYER_STATE 18, PLAYER_EVENT 19 e Ping 104 = unreliable sem retry. IDs removidos nunca reutilizados (1 POSITION, 2 ANIM, 3 ID legado, 5 REQUEST_PLAYERS, -1/-2/-3/-6/-7 legados). CONFIG_SYNC 16 = marcador int 16 + 8 bools nesta ordem exata: AllowTeleport, ShareAbilities, ShareStoryOnly, ShareWorldEvents, ShareDoorsAndLevers, ShowNicknames, ClientColors, EntitySync. Corpo legado preservado byte-identico (inclui int inicial com o proprio ID); strings = int32 length + ASCII. Servidor UDP porta padrao 7777, 1-10 jogadores, IPv4 manual sem descoberta LAN.

## Sincronizacao do mundo — alavancas, portas e eventos globais
- source: docs/world-sync.md
- type: protocol
- content: Identidade de objeto = MoonGuid(A,B,C,D) em 4 ints. SYNC_LEVER 11 = marcador + MoonGuid(4) + direction(1) = 24 B (relay 28 B), confiavel ACK+retry 250 ms x3. SYNC_DOOR 12 = marcador + MoonGuid(4) = 20 B (relay 24 B); abrir e o evento, sem campo de estado. SYNC_WORLDEVENT 14 = marcador + MoonGuid(4) + state(1) = 24 B (relay 28 B), confiavel. Regras obrigatorias nos aplicadores: IsSyncing=true durante aplicacao (sem eco), deduplicacao (_openedDoors Contains/Add; comparar estado antes de aplicar), so o jogador local publica e receptor nunca republica. Fora do escopo: SavePedestal (save/teleporte por jogador), Sein.World.Keys/Events e SeinWorldState (derivados, follow-up), TimedDoor (a confirmar), SYNC_BREAKABLE 13 (sem classe Breakable no vanilla, servidor so loga), Door de transicao de cena. Valores int de LeverDirections e estado aberto de CurrentState a confirmar em run.

## Phase 2: reescrita total do core do servidor — transporte, sessao e confiabilidade
- source: docs/server-rewrite-CONTEXT.md
- type: protocol
- content: Novo core em camadas Transport (UdpClient async/await + Channel, envelope magic+versao+seq+clientId+packetId, BinaryPrimitives/Spans little-endian, validacao de length) / Session (IDs incrementais nunca reutilizados em ConcurrentDictionary, handshake Hello/Welcome/Confirm, heartbeat cliente 2 s, timeout servidor 10 s, endpoint fixo + token por sessao) / Game (regras Ori, handlers, comandos) — sem estatico global mutavel, com ILogger + CancellationToken. PLAYER_STATE 18 = unreliable sequenciado (repasse so se seq > ultima). Pacotes criticos = ACK + retry ate 3 tentativas. Relay imediato sem agregacao em tick. Quebra one-way total com builds antigos (sem fallback); redesenho de IDs e payloads autorizado desde que cliente+servidor mudem juntos e docs/protocol.md seja atualizado na mesma mudanca. Operacao: .NET 8, CLI --auto/--max-players/--port, comandos coop/tp/dummy/clientcolors/entitysync, logs em arquivo + console, config persistida entre restarts.
